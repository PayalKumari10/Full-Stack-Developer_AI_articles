When you come from a Full Stack background, most of your work is around text, forms, APIs, and databases. As you move into AI, one big shift is that models are no longer limited to text only. They can understand images, audio, and a mix of inputs together. This is where multi modal agents start to matter.

This article is a simple learning note about what multi modal agents are and how we can send images to a language model using Python.

---

## What is a Multi Modal Agent

A multi modal agent is an AI system that can understand more than one type of input at the same time.

In simple words, instead of reading only text, it can also look at images, listen to audio, or handle different formats together.

For example:

* Text only model: answers questions from text
    
* Multi modal model: answers questions using text plus an image
    

This is useful when text alone is not enough. Think of image captions, document scanning, product images, or medical reports.

## Why Multi Modal Matters for Developers Moving into AI

As developers, we often build real products. Real products deal with photos, screenshots, PDFs, camera input, and user uploads.

Multi modal agents help you:

* Build smarter features with less custom logic
    
* Let the model understand context from images
    
* Reduce manual image processing code
    

If you already know APIs and backend logic, this fits naturally into your workflow.

## Sending Images to an LLM Using Python

Let us break the example step by step.

### 1\. Loading Environment Variables

First, we load environment variables. This is where the API key is stored.

```python
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()
```

#### What this does

* `load_dotenv()` loads variables from a `.env` file
    
* This keeps your API key safe and out of the code
    

This is a common practice in Full Stack apps too.

### 2\. Creating the OpenAI Client

```python
client = OpenAI()
```

#### What this does

* Creates a client object
    
* This client is used to send requests to the model
    

Think of it like creating a database or API client.

### 3\. Sending Text and Image Together

Here is the main part where multi modal behavior happens.

```python
response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[
        {
            "role": "user",
            "content": [
                {
                    "type": "text",
                    "text": "Generated a caption for this image in about 50 words"
                },
                {
                    "type": "image_url",
                    "image_url": {
                        "url": "https://images.pexels.com/photos/4065617/pexels-photo-4065617.jpeg"
                    }
                }
            ]
        }
    ]
)
```

#### What is happening here

* We are sending both text and image in one request
    
* The text tells the model what to do
    
* The image gives visual context
    

This is why it is called multi modal. The model reads the instruction and looks at the image before responding.

### 4\. Printing the Output

```python
print("Response:", response.choices[0].message.content)
```

#### Output (example)

```bash
Response: A person sitting on a wooden floor using a laptop, focused on work. The natural light and simple setting suggest a calm, productive environment, possibly at home or in a quiet workspace.
```

#### Explanation

* The model analyzed the image
    
* It generated a caption based on what it saw
    
* No image processing code was written by us
    

This is powerful because the intelligence comes from the model, not custom logic.
